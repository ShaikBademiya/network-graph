# Network Graph
A simple python setup for creating network graph using the flight routes and visualising it.

## Usage

### Installation of required packages
```bash
$ pip install -r requirements.txt
```

### Execution
```bash
$ python routes_graph.py
```
The `routes.py` script generates a `routes_net.html` which contains the network. Open the generated html file to see the network.
